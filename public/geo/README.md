Boundary layers used by every map (generated by `npm run geo:prepare`, see docs/MAPS.md):

- `andhra-pradesh-districts.geojson` – 28 current districts (properties: lgdCode, name), rebuilt from mandals
- `andhra-pradesh-mandals.geojson` – 696 mandals (lgdCodes, district, districtLgd, acNo)
- `andhra-pradesh-assembly-constituencies.geojson` – 175 assembly constituencies (acNo, name, reservation, loksabha, district)
- `andhra-pradesh.geojson` – state outline of the 28 districts
- `andhra-pradesh-soi.geojson` – Survey of India reference outline (via DataMeet, CC BY 4.0; predates 2014)

data/geo/boundaries-report.json lists sources, match statistics and every unmatched name.
