# Your images and logos

Drop files here with exactly these names. The site picks them up on the next page load; until then it
shows the built-in fallback, so nothing breaks while a file is missing. During `npm run dev` a dashed
note on each empty slot names the file to add (never shown in production). Full guide: docs/ASSETS.md.

| File | Used for | Size / format |
|---|---|---|
| brand/logo.svg (or logo.png) | Header and auth pages | Square, SVG preferred; PNG at least 192x192 |
| hero/citizens.webp (or .jpg/.png) | Landing hero: behind the headline, full width (text sits on the left) | 1920x800 or larger, landscape; people on the right half |
| landing/vision.webp | "Our Vision & Mission" card: right side, fading under the text | 800x600 or larger |
| landing/partners.webp | "Partner with Us" card: right side, fading under the text | 800x600 or larger |
| admin/sidebar-building.webp | Bottom of the admin sidebar | 456x380 |
| partners/*.svg | Partner logos (only with written permission) | SVG |

Record the source and licence of every image in CREDITS.md.
